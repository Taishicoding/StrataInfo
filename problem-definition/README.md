# Shōmei — South Australian strata problem overview

This is a standalone, static website. It does not depend on the main Shōmei product site and contains no build step.

## Deploy to Vercel

1. Push the repository to GitHub, GitLab or Bitbucket.
2. In Vercel, import that repository.
3. Set **Root Directory** to `problem-definition`.
4. Choose **Other** as the framework preset. Leave Build Command and Install Command empty. Set Output Directory to `.`.
5. Deploy. The `index.html` file is the site entry point.

If this folder is copied into its own repository, use `.` as the Root Directory instead. The site uses Google Fonts and external links to legislation and sources; those links require an internet connection.

## Content notes

Legal information is general and linked to its references in the page. Management-fee figures are estimates from a 2026 commercial market guide, not government data or quotes for a particular scheme. Fees vary by lot count, scope, disbursements and building complexity. Review the source link and confirm prices with individual strata managers before relying on any estimate.
